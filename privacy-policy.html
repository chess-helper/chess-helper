Политика конфиденциальности — AlexChessPro

Последнее обновление: 19 октября 2026 г.

1. Назначение расширения

AlexChessPro предназначен для анализа шахматных позиций на Chess.com и Lichess с помощью локального шахматного движка Stockfish.

2. Какие данные обрабатывает расширение

Для выполнения шахматного анализа AlexChessPro считывает текущую шахматную позицию со страницы Chess.com или Lichess.

Шахматная позиция обрабатывается локально на компьютере пользователя с помощью Stockfish и не передается на сервер лицензирования.

Для работы пробного периода и системы лицензирования расширение создает случайный идентификатор устройства (device_id).

Этот идентификатор передается по защищенному HTTPS-соединению на сервер лицензирования AlexChessPro: api.homark.ru.

3. Активация лицензии

При активации полной версии на сервер лицензирования передаются:

  • лицензионный код, введенный пользователем;
  • случайный идентификатор устройства (device_id).

Эти данные используются исключительно для проверки лицензии, определения статуса доступа и предотвращения повторного использования одного лицензионного кода на разных устройствах.

4. Пробный период

AlexChessPro предоставляет пробный период. Для его работы сервер может хранить дату начала пробного периода, дату окончания и идентификатор устройства.

5. Локальное хранение данных

Расширение может хранить локально в Chrome:

  • настройки анализа;
  • выбранную глубину анализа;
  • количество отображаемых стрелок;
  • состояние включения расширения;
  • идентификатор устройства;
  • кэшированный статус пробного периода или лицензии.

6. Stockfish

Шахматный движок Stockfish входит в состав расширения. Он запускается локально в браузере пользователя.

Шахматные позиции, ходы и результаты анализа не отправляются на сервер лицензирования.

7. Данные, которые AlexChessPro не собирает

AlexChessPro не собирает:

  • имя пользователя;
  • адрес электронной почты;
  • пароли Chess.com или Lichess;
  • платежные или банковские данные;
  • личные сообщения;
  • медицинские данные;
  • географическое местоположение;
  • историю поисковых запросов.

8. Сторонние сервисы

Расширение взаимодействует со следующими сервисами:

  • Chess.com — для получения текущей шахматной позиции и отображения элементов анализа на шахматной доске.
  • Lichess.org — для получения текущей шахматной позиции и отображения элементов анализа на шахматной доске.
  • api.homark.ru — исключительно для проверки пробного периода и лицензии AlexChessPro.

9. Передача данных третьим лицам

AlexChessPro не продает пользовательские данные и не передает их третьим лицам для рекламы, кредитования или иных целей, не связанных с работой расширения.

10. Аналитика и отслеживание

AlexChessPro не использует рекламные трекеры, аналитические пиксели или технологии отслеживания поведения пользователя для рекламы.

11. Безопасность

Обмен данными с сервером лицензирования выполняется через защищенное HTTPS-соединение.

12. Изменения политики

При изменении настоящей политики дата последнего обновления будет изменена в верхней части страницы.

13. Контакты

По вопросам, связанным с конфиденциальностью AlexChessPro, пользователь может обратиться к разработчику через контактные данные, указанные на странице расширения в Chrome Web Store.

Privacy Policy — Chess Helper for Lichess

Last updated: April 2026

1. Data We Collect

Chess Helper for Lichess does not collect, store, or transmit any personally identifiable information. We do not collect your name, email address, location, or any other personal data.

2. Local Storage

The extension stores the following data locally on your device using Chrome's built-in storage API:

  • Extension settings (analysis depth, number of arrows, enabled/disabled state)
  • Activation status (whether a valid activation code has been entered)
  • An anonymous device identifier used solely to prevent reuse of activation codes on multiple devices

This data never leaves your device and is not accessible to us.

3. Activation Code Verification

When you enter an activation code, it is sent to our database (Supabase) solely to verify its validity and mark it as used. No personal information is associated with this process — only the anonymous device identifier and the code itself.

4. Stockfish Engine

On first use, the extension downloads the Stockfish chess engine from a public CDN (unpkg.com). This is a one-time download. No data about your chess games, moves, or positions is ever sent to any server — all analysis happens entirely within your browser.

5. Third-Party Services

The extension interacts with:

  • lichess.org — to read the current board position and display move suggestions. No data is sent to lichess beyond normal page interaction.
  • Supabase — for activation code verification only.
  • unpkg.com — to download the Stockfish engine on first run.

6. No Tracking

We do not use analytics, tracking pixels, cookies, or any other tracking technologies.

7. Changes to This Policy

If we make changes to this privacy policy, we will update the date at the top of this page.

8. Contact
